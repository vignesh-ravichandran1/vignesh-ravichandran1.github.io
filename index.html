About

I'm a Lead Software Engineer at Interac Corp, where I build the backend systems behind Interac e-Transfer and the Enhanced Reconciliation File (ERF) that Canadian financial institutions use to reconcile payments.

I've spent my career building Java and Spring services. That includes REST microservices built test-first, batch pipelines, and API contracts written with OpenAPI. Before Interac, I built the Cronus Platform from scratch at Telna. At Wipro, I worked on enterprise systems for Hewlett Packard Enterprise and Mitsubishi Fuso.
